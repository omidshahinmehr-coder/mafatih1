# مفاتیح الجنان — اپلیکیشن اندروید

اپلیکیشن بومی اندروید (Kotlin) برای مطالعه کتاب مفاتیح الجنان، تولید شده از فایل Word اصلی
(`mafatih.htm`). شامل:

- فهرست کامل کتاب (باب / فصل / دعا و زیارت) در نوار کناری قابل باز و بسته شدن
- جستجوی تمام‌متن در محتوا و فهرست (با نرمال‌سازی حروف عربی/فارسی مثل ي↔ی و ك↔ک)
- امکان تغییر فونت (پیش‌فرض سیستم یا فونت استعداد Estedad که همراه برنامه است)
- تغییر اندازه قلم
- ۴ تم رنگی: روشن، کرم (مطالعه راحت)، تیره، شب
- امکان مخفی/نمایش ترجمه فارسی
- انتخاب متن با لمس طولانی و اشتراک‌گذاری/کپی (از طریق منوی انتخاب متن استاندارد اندروید،
  و همچنین با لمس طولانیِ عنوان هر دعا برای اشتراک‌گذاری مستقیم)
- **نشان‌گذاری (ستاره):** روی ستاره‌ی کنار هر عنوان دعا/زیارت بزنید تا به «علاقه‌مندی‌ها»
  اضافه شود؛ از آیکون بوکمارک در نوار بالا لیستشان را ببینید و با یک تپ به آن‌ها بروید.
- **ادامه‌ی خودکار مطالعه:** آخرین جایی که در اپ باز بوده، خودش ذخیره می‌شود و با باز کردن
  دوباره‌ی اپ، مطالعه از همان‌جا ادامه پیدا می‌کند (بدون نیاز به کار دستی).
- **هایلایت نتیجه‌ی جستجو:** عبارت پیداشده در هر نتیجه با رنگ زرد مشخص می‌شود تا محل دقیق
  تطبیق در متن معلوم باشد.
- آیکون اختصاصی برنامه (مدال آبی مفاتیح الجنان) برای لانچر و آیکون‌های adaptive

## ساختار پروژه

```
app/
  src/main/
    java/com/mafatih/reader/   کد Kotlin
    res/                       چیدمان‌ها، رنگ‌ها، آیکون‌ها، فونت
    assets/data.json           متن کامل کتاب (استخراج‌شده از mafatih.htm)
.github/workflows/android-build.yml   بیلد خودکار APK با GitHub Actions
```

## ساخت خودکار با GitHub Actions

با هر push به شاخه `main` یا `master`، یا اجرای دستی از تب Actions، ورک‌فلو
`.github/workflows/android-build.yml` به‌صورت خودکار:

1. JDK 17 و Android SDK را نصب می‌کند
2. Gradle 8.7 را برپا می‌کند (بدون نیاز به گنجاندن Gradle Wrapper در مخزن)
3. دستور `gradle assembleDebug` را اجرا می‌کند
4. فایل خروجی `app-debug.apk` را به‌عنوان Artifact بارگذاری می‌کند

خروجی را از تب **Actions ← اجرای مربوطه ← Artifacts** روی گیت‌هاب دانلود کنید.

> برای بیلد نسخه release امضاشده (قابل انتشار در Google Play)، باید یک keystore
> بسازید و signingConfig را در `app/build.gradle.kts` اضافه کنید؛ این پروژه فعلاً
> فقط بیلد debug را در CI انجام می‌دهد.

## ساخت محلی (اختیاری)

اگر می‌خواهید در Android Studio باز کنید:

1. پروژه را در Android Studio باز کنید (Open an existing project)
2. Android Studio به‌صورت خودکار Gradle Wrapper را می‌سازد و وابستگی‌ها را دانلود می‌کند
3. Run ▶ را بزنید

یا از خط فرمان (در صورت نصب بودن Gradle 8.7 روی سیستم):

```bash
gradle assembleDebug
```

فایل خروجی در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## داده کتاب

فایل `app/src/main/assets/data.json` از روی `mafatih.htm` اصلی به‌صورت خودکار
پردازش شده است. فهرست (باب/فصل/دعا) با تشخیص الگوهای متنی (نه با تگ‌های HTML، چون
فایل اصلی ساختار عنوان‌بندی نداشت) ساخته شده و ممکن است در چند مورد جزئی، عنوان‌ها
کامل تشخیص داده نشده باشند — اما جستجوی تمام‌متن روی کل کتاب، مستقل از فهرست، کار می‌کند
و همه‌چیز را پوشش می‌دهد.

## فونت

فونت **استعداد (Estedad)** — فونت متن‌باز فارسی/عربی — همراه برنامه است
(`app/src/main/res/font/estedad.ttf`, پروژه اصلی:
https://github.com/aminabedi68/Estedad). برای افزودن فونت‌های بیشتر:

1. فایل `.ttf` را در `app/src/main/res/font/` قرار دهید
2. یک `font-family` XML مشابه `estedad_family.xml` برایش بسازید
3. در `PrefsManager.kt` مقدار جدیدی به `enum AppFont` اضافه کنید
4. در `MainActivity.applyStyle()` و در `sheet_settings.xml` گزینه جدید را اضافه کنید
